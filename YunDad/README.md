# 孕爸爸 (YunDad/PregDad)

专业的孕期陪伴 App，为准爸爸提供全面的孕期知识、食谱推荐、饮食打卡和待产包管理。

## 技术栈

- **Next.js 16** - React 框架
- **TypeScript** - 类型安全
- **Tailwind CSS 4** - 样式
- **shadcn/ui** - UI 组件库
- **Prisma + SQLite** - 数据库
- **Zustand** - 状态管理

## 快速开始

```bash
# 安装依赖
npm install

# 初始化数据库
npx prisma db push

# 启动开发服务器
npm run dev
```

## 功能模块

- 🏠 首页 - 宝宝信息、饮食计划、每日推荐
- 🍽️ 食谱 - 推荐食谱、营养知识、忌口提示
- ✅ 打卡 - 饮食打卡、积分系统
- 🎒 待产包 - 智能清单、进度追踪
- ❤️ 健康 - 胎动计数、产检提醒、宫缩记录
